# 3. PRODUCT VISION

The application is a **Virtual Teaching Platform** connecting students with tutors.

A student should be able to:

1. Register/login.
2. Search for tutors.
3. Filter tutors by subject.
4. View tutor profiles.
5. See tutor bio, subjects, hourly rate, and availability.
6. Select a date/time.
7. Book a tutoring session.
8. View upcoming/past sessions.
9. Track booking status.
10. Access learning resources provided by tutors.

A tutor should be able to:

1. Register/login as a tutor.
2. Create/update their tutor profile.
3. Add subjects they teach.
4. Set their hourly rate.
5. View incoming booking requests.
6. Accept/reject/cancel sessions.
7. Mark completed sessions.
8. Upload/add learning resources.
9. View their teaching dashboard.

# 13. SECURITY

Implement Spring Security + JWT properly.

Requirements:

- Password hashing with BCrypt
- JWT generation
- JWT validation
- Authentication filter
- Stateless authentication
- Role-based authorization
- Protected endpoints
- Public authentication endpoints

Students must not be able to modify tutor profiles.

Tutors must not be able to impersonate students.

Users must only be able to modify data they are authorized to modify.

Return appropriate HTTP status codes:

```text
200 OK
201 CREATED
400 BAD REQUEST
401 UNAUTHORIZED
403 FORBIDDEN
404 NOT FOUND
409 CONFLICT
500 INTERNAL SERVER ERROR
```
